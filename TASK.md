# Задачі: Telegram-бот із ШІ-агентом

## Мета

Реалізувати Telegram-бота на Python із фоновим ШІ-агентом на Google Agent Development Kit (ADK). Агент працює через локальну Ollama з моделлю `gemma4:12b`, може перезапускати процес бота та створювати на запит користувача Python-інструменти, додаткових агентів і субагентів на ADK. Для кожного агента можна вибрати іншу встановлену в Ollama модель.

## Результат реалізації та перевірок

Реалізацію завершено без Docker. Залежності зафіксовані в `uv.lock`; запуск, налаштування,
контракти розширень, обмеження платформ і відновлення описані в `README.md`.

Перевірено на macOS, Python 3.12.16, Google ADK 2.14.1, LiteLLM 1.109.1:

- 37 автоматизованих тестів пройшли, включно з реальною Ollama `gemma4:12b`.
- Діалог, типізовані tool calls, створення інструмента природною мовою та його подальший виклик.
- Генерація й виконання ADK-агента та субагента через делегування.
- Інша встановлена модель `cryptidbleh/gemma4-claude-sonnet-4.6:latest` і збереження вибору.
- Запит перезапуску від реальної моделі, два запуски worker зі збереженим станом та
  справжній перезапуск дочірнього процесу supervisor.
- Seatbelt: заборона читання сторонніх файлів, мережі, fork і секретів оточення; явний
  дозвіл workspace (постійний FILESYSTEM_ROOT); завершення за таймаутом, лімітом пам’яті та скасуванням.
- Встановлення дозволеної wheel-залежності `six==1.17.0` в окреме середовище розширення.
- Дедуплікація updates, ізоляція сесій, відкат, відхилення некоректних версій та резервна копія.
- Ruff, форматування, mypy, узгодженість залежностей і збірка wheel/sdist.

Позначки критеріїв Telegram у розділі 8 означають перевірку повного коду адаптера з
підміненою Bot API, без надсилання повідомлень у справжні чати. Поведінка моделі, ізоляції,
баз даних і дочірніх процесів у відповідних інтеграційних тестах справжня.

Окремі перевірки середовища користувача:

- [ ] Додати власний `TELEGRAM_BOT_TOKEN` у `.env`, за потреби обмежити `ALLOWED_USER_IDS`, виконати `doctor`
  і перевірити живий Bot API polling, відповіді й `/restart` у власному Telegram-чаті.
- [ ] Якщо потрібен Linux, перевірити backend bubblewrap на цільовому дистрибутиві;
  у поточному середовищі виконані macOS-тести.

Google ADK видає upstream DeprecationWarning щодо внутрішнього використання `plugins`
в AgentTool; перевірки проходять, власний код не залежить від цього deprecated аргументу.
